## Terminology drift

- TD Flow E step 5 "keyed by (server_id, issuer)" vs DM §3 entry `oauth:{server_id}` with
  an `issuer` field → D7 aligns on "keyed by server id, bound to issuer".
- "Parked handlers" (TD Flow E) now means `redirect_handler` raising
  `AuthorizationDeferred` (D1).
- "JSON-RPC error" for modern input requests → "client-side abort" (S-1 vocabulary, D3).
- `sign-out` (PRD) = `sign_out` (API) — consistent; no change.

a Phase 4 Done criterion: F4-07/F4-08 run against the fixture AS (F4-09a, which resolves the

dependency of F8-07, so release `0.1.0` cannot be tagged until `S-4.md` records a real-AS
result or the documented fallback.
