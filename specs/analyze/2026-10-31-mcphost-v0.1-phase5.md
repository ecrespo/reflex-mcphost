## Constitution check

- **Art. 1** — no server code ships: wheel *and* sdist checked for `tests/`, `spikes/`,
  `specs/`, `changes/`, `mcp.server` imports (F5-06a); fixture Servers stay in `tests/`.
- **Art. 2** — adapters subclass the frameworks' own extension points (`AbstractToolset`,
  `BaseTool`) and use their own error channels (`ToolFailed`, `ToolException`); no
  validation or retry logic re-implemented; private `_to_args_and_kwargs` pinned by a
  contract test; release uses `uv build`/`uv publish` and PyPI Trusted Publishing (DD-015).
- **Art. 3** — single effect path holds: `Toolset.call` → `Invoker.call` only; consent,
  audit and validation stay in the Invoker; the AST test covers `core.toolset` and
  `adapters.*`, and F5-05 adds a non-vacuous check that the Toolset reaches `Invoker.call`.
  The PydanticAI adapter defines the framework's `call_tool` hook but calls no
  `call_tool`.
- **Art. 4** — layering `core → toolset → adapters` preserved by D1 (no upward import from
  `core.host`); `core` and `toolset` import no framework (existing forbidden contract +
  REQ-TLS-008 subprocess test, also against the installed wheel); adapters independent of
  each other (existing) and of `core` (new contract); adapters are extras.
- **Art. 5** — agent text built from Server output and the Invoker's redacted
  `error.message`; no argument values in any error text or log; F4-09b redaction test
  extended to the Toolset path; no PyPI token exists (OIDC, job-scoped `id-token: write`).
- **Art. 6** — not touched (no config writes in Phase 5).
- **Art. 7** — every RF-TLS MUST has a planned citing test on both eras; strict REQ gate
  extended to `TLS`; real fixture Servers in integration tests, no real LLM needed.
- **Art. 8** — no new blocking I/O; `Toolset.list()` is sync over in-memory snapshots.
- **Art. 9** — gaps went through delta `changes/_archive/2026-10-phase5-prep` (folded), not
  silent edits; SemVer pre-release `0.1.0a1`; Conventional Commits.
