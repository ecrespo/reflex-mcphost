## Constitution check

- **Art. 1** — no server code: the reference app is a Reflex web app (the Host's own UI), not
  an MCP server; no `mcp.server` import (existing contract); fixtures stay under `tests/`;
  `check_wheel.py` gains `app/web` presence and `.web/`/`.states/` absence (F6-08).
- **Art. 2** — Reflex used through its documented extension points (`api_transformer`,
  `register_lifespan_task`, `on_load`, background events); the two private test hooks are
  pinned by a contract test; deprecated sampling/roots/logging labelled in the UI.
- **Art. 3** — the UI is a `Prompter`: human decisions reach core only as Prompter return
  values; UI invocations go through `Invoker.start` with `Consumer.human()`; the AST
  single-effect-path test scans `ui/` and `app/` (it walks the whole package); prompter
  exceptions fail closed in core; unattributed prompts restricted to `allow_once`/`deny`.
- **Art. 4** — `ui` on top of `core`/`toolset`, `app` on top of `ui` (layers contract);
  `core`/`toolset` import no `reflex` (existing); new contract `ui.models` ↛ `reflex`;
  `servers` / `--version` import no `reflex`; embeddability test (F6-09a).
- **Art. 5** — keys-only rendering, no tokens or authorization URL in state/logs, Server text
  as plain text, single-origin guard (HTTP, websocket, static UI), `localhost` reserved for
  the sandbox proxy, seeded redaction test extended to UI view models.
- **Art. 6** — UI writes configuration only through `ServerRegistry` (enable/disable →
  `mcphost.toml` override); byte-identical third-party files asserted (F6-04, F6-08).
- **Art. 7** — every RF-UI MUST and the Phase 6 NFRs have planned citing tests; real fixture
  Servers on both eras; strict REQ gate gains `UI`; `ui`/`app` inside the ≥ 80 % total gate.
- **Art. 8** — no blocking I/O on the event loop (config loaded at import before serving,
  DB pre-flight in the CLI process); typed public `ui` surface with docstrings.
- **Art. 9** — all gaps routed through delta `changes/_archive/2026-11-phase6-prep` (folded);
  Conventional Commits; no release in Phase 6 (`0.1.0b1` is F7-07).
