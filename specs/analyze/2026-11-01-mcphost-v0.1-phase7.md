## Constitution check

- **Art. 1** — no server code: the sandbox proxy serves one static Host page (it is the Host's
  UI, not an MCP Server); MCP Apps constants defined in `core.apps`, never imported from
  `mcp.server.apps`; fixture Server and vendored Views only under `tests/` (wheel check).
- **Art. 2** — host side of MCP Apps `2026-01-26`, protocol facts re-read from the pinned
  spec (table above); deviations documented (no conversation methods; render after
  completion; stricter default CSP; `domain` ignored); `advertise` pinned by the SDK
  contract test.
- **Art. 3** — App `tools/call` only through `Invoker.call` with `Consumer.app(server_id)`;
  App scope enforced **and audited** in the Invoker (step 1a, D1); consent evaluated for
  `app:<server_id>` and answered only by the human; no `ClientSession` access from `ui` (AST
  test); fail-closed: a bridge or port error replies with an error, never calls the Server.
- **Art. 4** — `core.apps` pure (no Reflex, no I/O, ports injected); `ui.proxy` Reflex-free
  (new import-linter contract, F7-03); `ui.apps_bridge` is the only Reflex adapter; layers
  contract unchanged.
- **Art. 5** — distinct proxy origin on both stacks with `Host` check and pinned UI origin;
  validated declared-domains-only CSP without `'unsafe-eval'` (REQ-APP-014); data-only relay
  with source + origin filter (D4); no device permissions (REQ-APP-011); size and concurrency
  limits (REQ-APP-013); `ui/open-link` restricted and confirmed (REQ-APP-015); View state in
  memory only, log stream gets method → outcome only, redaction test extended; residual
  risk (View self-navigation) unchanged in TD §6.1 and listed in the changelog.
- **Art. 6** — not touched (no configuration writes in Phase 7).
- **Art. 7** — every REQ-APP MUST has planned citing tests on real fixture Servers (both
  eras) and in three browser engines; strict gate gains `APP`; `core.apps` inside the ≥ 90 %
  core gate.
- **Art. 8** — proxy and origin-pair check async (`anyio`, `to_thread` for `getaddrinfo`);
  public additions (`set_mcp_apps`, `append_log`, `mcp_app_frame`, `HostRuntime.apps`) typed
  and documented.
- **Art. 9** — all gaps routed through delta `changes/_archive/2026-11-phase7-prep` (folded);
  publishing `0.1.0b1` is an owner action (F7-07b), never performed by the agent.
